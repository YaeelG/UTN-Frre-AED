## Nivel de prioridad (en mi caso)
(siendo 1 el más importante)

    1. Búsqueda: Aprender la estructura de los tipos de algoritmos de busqueda y ordenamiento. Suelen ser largos los ejercicios.

    4. Corte de control: procedimientos de corte para tratar cada corte. Proceso individual. El registro debe estar identificado por una clave compleja. datos deben estar ordenados con respecto a los campos que producen los cortes de control, ya que así los datos quedan agrupados según se requiere(revisar ejercicio 2.2.13.frre)
